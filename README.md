# 🌍 Far Away App

**Far Away** is a React-based travel companion app inspired by Jonas Schmedtmann's project. Effortlessly manage your packing lists, track what you’ve packed, and stay organized before every trip. Built with modern web tools and a clean, responsive design.

---
## 🔗 Live Demo

[Visit Live App](https://far-away-2025.netlify.app/)

## ✨ Features

- ✅ Create, edit, and delete packing list items.
- 🧳 Mark items as packed or unpacked.
- 📱 Responsive UI for mobile and desktop.
- 🔄 Auto-sorting by packed status.
- 💾 State persistence using local storage (optional enhancement).

## 🚀 Getting Started

Follow these steps to run the project locally.

### 📦 Prerequisites

Ensure you have [pnpm](https://pnpm.io/) installed:

```bash
npm install -g pnpm
```

## ⚙️ Installation
1. Clone the repository:
```bash
git clone https://github.com/Pritam8968/far-away.git
```
2. Navigate to the project directory:
```bash
cd far-away
```
3. Install dependencies:
```bash
pnpm install
```

## 🧪 Run the App
Start the development server:
```bash
pnpm dev
```
Then open your browser and go to:
📍 http://localhost:5173
